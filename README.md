## chat_bot 

esse projeto e um chat bot feito em python, ele usa o gemini IA como base permitindo q converese com o gemini IA pelo terminal 

## ferramentas usadas
- Python
- Google GenAI SDK
- python-dotenv

## como instalar
Clone o repositório:

git clone https://github.com/shiroRS/projeto-de-CHATBOT.git

Instale as dependências:

pip install -r requirements.txt

## Configuração da API

Este projeto utiliza a API Gemini.

Crie um arquivo `.env` na raiz do projeto:

GEMINI_API_KEY=sua_chave_aqui
